## Compatibility and hosting considerations

- WordPress 7.1.5 and PHP 8.3 are recent. Confirm the chosen WooCommerce release explicitly lists compatibility before activation.
- Hostinger hCDN is serving cached pages. Cart, checkout, My Account and WooCommerce session cookies must be excluded from full-page caching.
- The REST API is reachable, but authenticated `POST`, `PUT` and `DELETE` handling still needs testing after an Application Password is created.
- Pretty permalinks must be enabled for WooCommerce REST API use.
- The active plugin list, database limits, memory limit, cron behavior, upload limit and filesystem permissions require authenticated Site Health or WP-CLI access.

## Current blocker

The owner must create a revocable WordPress Application Password, activate WooCommerce after taking a backup, and generate WooCommerce read/write REST keys. Put them only in the untracked `.env` file. Do not place a primary WordPress password in this repository.
